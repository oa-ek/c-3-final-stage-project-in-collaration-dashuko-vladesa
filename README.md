# Документація інтеграції API (LogisticsGroup)

## Сценарій інтеграції
**Назва:** Комплексна логістична маршрутизація, моніторинг інфраструктури та погодних умов.
**Проблема користувача:** При формуванні складних рейсів логіст стикається з проблемою ручного розрахунку точної відстані по автошляхах та часу вантажівки в дорозі. Водію для безпечного виконання рейсу необхідна актуальна інформація про погодні умови в місті прибуття. Адміністратору, у свою чергу, потрібен зручний просторовий аналіз інфраструктури (візуалізація мережі відділень) на інтерактивній карті.

## Використані зовнішні API

| API | Endpoint | Отримані дані | Кешування |
|---|---|---|---|
| **Nominatim (OSM)** | `/search?q=...&format=json` | Географічні координати (широта, довгота) відділень | 24 год (IMemoryCache) |
| **OpenRouteService** | `/v2/directions/driving-hgv` | Точна відстань (км), час у дорозі для вантажівок | Ні |
| **Open-Meteo** | `/v1/forecast?latitude=...&longitude=...` | Температура, опади, погодні умови | 10 хв (IMemoryCache) |

## Fallback-стратегії (Стійкість системи через Polly)
Завдяки конфігурації `AddStandardResilienceHandler` (Polly), наша система захищена від збоїв сторонніх сервісів:
- **OpenRouteService недоступний:** Автоматичний розрахунок маршруту вимикається, логіст отримує повідомлення "Сервіс маршрутизації тимчасово недоступний" і може ввести відстань та час вручну, щоб не блокувати бізнес-процес.
- **Open-Meteo недоступний:** Блок із прогнозом погоди на панелі водія приховується або відображає статус "Дані про погоду недоступні".
- **Nominatim недоступний:** Якщо нове відділення не змогло отримати координати, воно просто не відображається на візуальній карті (Leaflet), але продовжує повноцінно працювати в базі даних та таблицях.

## Власний Web API (API Provider)
Для інтеграції нашої логістичної системи з іншими сервісами ми реалізували власний відкритий API.
- **Controller:** `ParcelsApiController`
- **Swagger UI:** `/swagger` (Доступна повна документація та можливість тестування endpoint-ів)
- **Тест:** `GET /api/ParcelsApi` (Отримання актуальних даних про відправлення)
